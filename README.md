# AG Website - Frontend

This is the frontend application for the Azentra Global Website, built with React, Vite, and Tailwind CSS.

## Tech Stack
- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Package Manager:** npm

## Prerequisites
- Node.js (Version 18.x or higher recommended)
- npm
